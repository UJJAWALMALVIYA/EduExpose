# English-Hindi Neural Machine Translation using Transformer

## Project Description

This project implements an English-to-Hindi Neural Machine Translation system using Transformer architecture. The IIT Bombay English-Hindi Parallel Corpus is used for training and evaluation.

The system utilizes the MarianMT Transformer model and provides translation through a Streamlit web interface.

## Features

* English to Hindi Translation
* Transformer-based Architecture
* Streamlit Web Interface
* Fine-tuning using IIT Bombay Corpus

## Technologies Used

* Python
* PyTorch
* Hugging Face Transformers
* Streamlit
* IIT Bombay Parallel Corpus

## Project Structure

* train.py : Model training script
* translate.py : Translation module
* app.py : Streamlit frontend
* model/ : Trained model files
* dataset/ : Dataset files

## Installation

pip install -r requirements.txt

## Run Application

streamlit run app.py
